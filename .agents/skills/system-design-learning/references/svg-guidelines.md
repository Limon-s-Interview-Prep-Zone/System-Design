# SVG Diagram Guidelines

## Location & Naming
- Target directory: `images/<topic-name>-<diagram-type>.svg`.
- Embed format: `![Description](images/<topic-name>-<diagram-type>.svg)`.

## Visual Standards
1. **Vector Quality**: Clean shapes, crisp text, and proper bounding boxes (`viewBox="0 0 W H"`).
2. **Color Palette**:
   - Modern, high-contrast dark/light friendly colors (e.g., `#2b2d42`, `#8d99ae`, `#edf2f4`, `#ef233c`, `#3a86ff`, `#06d6a0`).
3. **Typography**: Use standard system sans-serif fonts: `font-family="system-ui, -apple-system, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif"`.
4. **Self-Contained**: Inline styles and attributes only. No external web font dependencies or unrendered scripts.
